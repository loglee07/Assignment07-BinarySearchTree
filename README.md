# Assignment 07: Binary Search Tree Operations

## Summary

This C++17 program implements a binary search tree from scratch. It supports insertion, searching, removal, inorder traversal, preorder traversal, postorder traversal, and height calculation. The program also demonstrates removing a leaf node, a node with one child, and a node with two children.

## How to Run

Compile the program:

    clang++ -std=c++17 main.cpp -o assignment07

Run the program:

    ./assignment07

Run the program and save its output:

    ./assignment07 | tee results.txt
